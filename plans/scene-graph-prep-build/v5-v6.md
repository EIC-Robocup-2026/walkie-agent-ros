## V6: bounded embedding services

**Built.**

- `src/walkie_vision/requests.py`: the codes, the caps, `ServiceJob`, `JobSlot`, `CurrentImage`, the request checks, `rectangle_quality` and `embed_crop_answer`.
- `EmbedText`: 16 texts at most, 512 characters each, none blank, a 2 s deadline, and it works before the first image.
- `EmbedCrop`: the newest colour and depth only, with exact gates: same frame and size, stamps within 5 ms, image at most 300 ms old in ROS time, request at most 5 ms ahead of ROS time, `timeout_s` above 0 and at most 5 s.

- One slot across the services, with `BUSY` for another request. A reentrant group, four executor threads, and a worker that a job can wake. The newest frame runs before the slot is freed.
- Monotonic deadlines and ROS image age. A late result is counted and discarded. The watchdog covers jobs. A service failure leaves the arrays and their counters alone.
- New parameters `embed_text_service`, `embed_crop_service`, `describe_crop_service` and `captions_enabled`, with sim names in `config/sim.yaml`.

## Decisions, with what each costs

V5:

- **Track id 0 follows the sampling formula as written.** An untracked object can be sampled like any other. Cost: a stream of id 0 objects shares one phase.
- **The short side is measured inside the image.** A box cut off by the edge counts by its visible part. Cost: none known.
- **Colour shares under either flag, when sampled and masked.** Cost: the work runs with crops alone too.
- **`fetch-models` always fetches CLIP.** Cost: about 335 to 571 MB on a machine that only runs HRI.
- **`allow_fake_embedder` only for injected providers.** Cost: a test that wants a fake on the real path must say so.
- **No CLIP warm-up.** Cost: the first sampled image or service job can be slow.
- **A bad vector row is dropped and the crop is kept.** Cost: that object has a crop with no vector.
- **`view_quality` only with geometry.** Cost: 0 on a sampled object without depth.
- **Sampling time counts in `build`, with no new stage.** V8 owns the stages. Cost: the log cannot split sampling from building yet.
- **An embedder exception fails the image, like any provider's.** Cost: a broken CLIP counts toward the 30 failures that restart the node.
- **Each slice adds its own flag.** Cost: none beyond the memory task's missing key above.

V6:

- **`CurrentImage` keeps the newest colour and depth, only with the flag on.** Cost: up to two large messages stay alive between images. HRI keeps nothing.
- **`NO_IMAGE` answers at once** instead of waiting out the timeout. Cost: a caller must retry on its own right after a start.
- **The gates run on the worker at job start, with no recheck after inference.** The header shows the true stamp. Cost: an answer can be slightly older than 300 ms when it arrives.
- **`EmbedText` failures carry the code as a message prefix,** because the type has no code field and types stay frozen. Cost: clients must parse the prefix.
- **The services always exist and answer `DISABLED` when off.** Cost: three more endpoints on HRI, with no model behind them.
- **`captions_enabled` true is refused at start.** Cost: none in this build. A caption slice must lift it.
- **`MODEL_UNAVAILABLE` only at shutdown.** Start refuses a missing model, so nothing else can reach it. Cost: none known.
- **`EXECUTOR_THREADS = 4` for every task, HRI included.** Cost: two more idle threads on HRI.
- **The latency counters show only with embeddings on.** The HRI line stays as it was. Cost: none.
- **The dim check runs at start and in the crop filler, not in the text filler.** Cost: a direct caller of the text filler has no such check.
- **The watchdog covers jobs.** Cost: a hung job restarts the node, like a hung image.
- **Job time has no latency stage.** V8 owns the stages. Cost: until then, job time shows only as a lower image rate.
- **The rate cap still applies to the frame after a job.** Cost: a request can wait a little longer for the slot.
- **`EmbedCrop` applies only positive area and overlap, not the 32 px sampler floor.** Cost: a very small box gets a low-value vector.
- **`DescribeCrop` validates nothing,** because it always answers `DISABLED`. Cost: a future caption slice adds the checks.
- **One failure warning, "a service job failed", throttled across both services.** Cost: one service's failures can hide the other's for 5 s in the log.
