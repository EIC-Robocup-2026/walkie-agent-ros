## Deviations

1. No type or hash change. Nothing here changes a wire contract.
2. Recipe: `env` is not on PATH under `--clean-env`, so the commands use `/usr/bin/env`,
   as earlier slices did. The `timeout` command is not on PATH either, so it was dropped.
3. `FindObjects` now leaves out `discarded` and `merged` objects and anchors with
   `geometry_valid` 0. The brief keeps old FindObjects behaviour with `memory_enabled`
   false. This changes the result only for rows that D6 introduces: legacy rows default
   to `geometry_valid` 1, and the old node writes no tombstones. Without the filter, a
   geometryless anchor would be returned at a zero box, which is a false place. The wire
   type did not change.
4. `use_sim_time` is refused at runtime also with `memory_enabled` false. A node's times
   must come from one clock. This narrows what `ros2 param set` could do on `db-node`.
   Under `use_sim_time` in that mode, `start_session` and `remember_person` also fail with
   the retryable prefix until the first `/clock` sample. Without `use_sim_time`, the
   behaviour is as before, because the node clock is wall time.
5. The lock also applies with `memory_enabled` false, as the brief says. A second `db-node`
   on the same file now exits 1. Two used to run, against ADR-0005.

## Decisions (what the brief did not settle, and the cost)

1. **One store per worker, restored each episode, in place of ADR-0016's new file per
   episode.** A new path would restart the ID counters, so one ID could name two objects
   across episodes. Cost: IDs differ between episodes, so a scenario cannot rely on a
   literal ID. The restore does also accept a new path, so a harness can still choose.
2. **Location name is the exact display name.** Cost: the agent's underscore names need a
   display-name entry in the world's locations file.
3. **Room-names file format is mine:** `schema_version` and a `rooms` map. Cost: the harness
   must write this exact form.
4. **Manifest keys are `map_id`, `baseline_rev`, `map_hash`, at the top of the folder. A
   manifest present means the store's revision must equal it.** That includes a nonempty
   manifest with an empty store. Cost: a rooms-only seed must be rebuilt once a baseline
   exists.
5. **A seed needs at least one room, keys match `[a-z][a-z0-9_]{0,63}`, and all room fields
   are required.** Cost: a map-row-only seed is not possible, so the old fallback on the
   harvest page is gone.
6. **A geometry_valid false anchor must give no center, size or yaw.** Zero placeholders are
   refused. Cost: reviewers cannot leave rough numbers in the file.
7. **Fingerprints are a form with provenance hashes.** The tool checks the form only, and
   cannot prove the hashes honest. Cost: honesty rests on the file's reviewer.
8. **Attribute vocabulary lives in `object_context` and is enforced by the seed tool, not by
   `add_catalogue_item`.** Cost: a later writer could add a value outside it until it calls
   `check_attributes`.
9. **The seed's `store_id` is the constant `seed`, `created_at` comes from `--date`, and the
   description is fixed text.** This is what makes rows repeatable. Room IDs follow sorted
   keys. Cost: room IDs are not stable across reseeds. Only anchor IDs are.
10. **`--replace` only replaces a seed, and a same-map replace needs `--previous-seed`.** Cost:
    a seed cannot be rebuilt from scratch at its own path without naming the old one. Delete
    it by hand to start a new lineage.
11. **A previous seed is read at schema 4 to newest, and restore requires a seed at newest.**
    Cost: an old seed must be rebuilt before it can be restored.
12. **Restore refuses an outgoing store with no `store_meta`, another map, another clock or a
    newer schema, and refuses a lone `-wal`.** No registration tool exists. Cost: a legacy
    people-only store cannot enter memory mode at its own path, and stays on the default mode.
13. **No `clock_kind` parameter.** The clock is derived from `use_sim_time`. Cost: none known,
    as long as `use_sim_time` is the only clock switch.
14. **`store_id` is refreshed on each start in both modes when a `store_meta` row exists.** The
    anchor refresh runs only in memory mode. Tombstones are not stamped, and the revision is not
    changed. Cost: one commit on every start of a seeded store, also in the default mode.
15. **`seed_sim` prints the normalized rooms to stdout, instead of writing a file.** It calls
    `write_seed` in-process. Cost: a caller who wants the file redirects stdout, and must cut the
    final report line.
16. **Not validated:** an anchor's center against its room's outline, and polygons with crossing
    edges. Cost: such an input passes. The docs list this.
17. **A temporary file can stay beside the target after a hard crash** (`.name.uuid.tmp`). It is
    harmless, and nothing cleans it up. Cost: disk.
18. **Memory mode never creates a store.** Cost: a store must be restored before its first start.
19. **`set_ros_time_override` on the first `/clock` sample,** so `_now` cannot read 0 before
    rclpy's own time source has fired. Cost: this leans on an rclpy clock method. If a later rclpy
    changes it, `test_people_timestamps_follow_the_sim_clock` would show it.
20. **ADR-0023 status is Proposed,** like ADR-0021 and ADR-0022. ADR-0005 and ADR-0020 gain status
    text only. Cost: the exception is not formally accepted until someone accepts ADR-0023.
21. **Small corrections beyond the seed contract on `harvest.md`:** the rooms query now says that
    `ListRooms` and `GetRoomContents` exist, because D1 made the old text stale. Cost: none.
