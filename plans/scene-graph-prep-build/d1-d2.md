4. D1 touches files its row does not list: `.github/workflows/test.yml`, `tests/conftest.py`, `README.md`, `docs/getting-started.md`, setup steps 8 and 10, `docs/setup/index.md`, `mkdocs.yml` and `docs/architecture/harvest.md`. 5. `src/walkie_database/map_config.py` is created in D2, while the brief lists it under D6. D2's acceptance needs "reject malformed/NaN/duplicate-key wrapper inputs", which needs a wrapper. It holds only YAML parsing and the digest call. D6 extends it.
6. ADR-0012 changed its title but keeps its file name, `0012-per-detection-clouds-any-frame.md`. It is Proposed, so rewriting is allowed. Renaming would break links for no gain.

## Decisions

| Decision | Cost |
| -------- | ---- |
| Clone with `--no-local`, so the clone shares no objects with the source | Copies 2.3 MB instead of hard-linking |
| The import tool reads the pin with PyYAML | It needs the pixi environment |
| `import-interfaces` is a separate task, and `build-msgs` does not depend on it, so a build never reaches the network | A fresh checkout runs two commands |
| Version bounds are taken from the solved versions | A later upgrade must edit the bound |
| `walkie_database_msgs/package.xml` does not name `vision_msgs`, because no type here uses it directly. Conda still provides it | None until a type uses it directly |
| ADR-0015 is not edited. ADR-0019 says it changes one consumer line, and setup step 8 has the current instructions | Someone reading ADR-0015 alone sees the old line |
| ADR-0019 and ADR-0020 are Accepted. Each says which part is in effect, and later slices add status text only | Accepted normally means in effect, and the seed lineage and gate parts are not built |
| Strict PGM: no comment directly after maxval, no comment in a P2 raster, no vertical tab or form feed, no trailing bytes | Some files that loose tools accept need a re-save. Loosening later changes no digest |
| `negate` must be a real integer 0 or 1. `0.0` and `false` are rejected | A hand-written YAML with those needs an edit |
| `pgm` must be `bytes`. `bytearray` and `memoryview` are rejected | The caller converts |
| Real values accept integers, because real maps have `0` in `origin`. An integer too large for a float is a ValueError | None |
| The wrapper also rejects YAML merge keys, because an explicit key overrides a merged one silently | A YAML using merge keys needs flattening |
| `5e-2` is rejected, because PyYAML reads it as a string. Noted in ADR-0020 | A consumer whose parser reads it as a number gets a digest where this wrapper refuses. Real maps use `0.05` |
| A missing YAML or image raises OSError in the wrapper, and bad content raises ValueError | A caller handles both |
| Golden vectors are portable JSON with hex images, so no binary file or `.gitattributes` change | A 26 KB fixture |
| No setup log step for D2. The instructions are in `database.md` | The setup log does not mention the helper |
| `database.md` lists what each new endpoint will do once served, with a warning that none is served yet | Later slices must update that table |
