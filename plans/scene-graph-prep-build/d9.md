## Decisions

- **`--build` reruns colcon incrementally in each worktree's own `ros2_ws`; only the
  client overlay is always built from an empty folder.** Cost: a stale artifact that
  colcon or CMake does not notice would survive in an installation. The hash
  comparison with the fresh overlay would catch it for `walkie_database_msgs`, but not
  for the two builds of `walkie_vision_msgs`.
- **The gate writes its own empty `colcon-defaults.yaml` in its run folder** and sets
  two workers, rather than reading `build-reports/colcon-defaults.yaml`. Both are `{}`.
  Cost: none today; a team defaults file would be ignored by the gate.
- **Both negative controls run inside every gate run, and must be caught for a pass.**
  `--negative-control` additionally lets the whole run fail on purpose. Cost: one extra
  probe process per run, about 0.5 s.
- **The import control is a probe only, with `--no-typesupport`.** It imports the
  database's own Python build into a vision process but never creates a node, so no
  wrong-typed peer joins the domain. Cost: it proves the path check, not a wire failure.
- **The store-row rule allows exactly ADR-0023's first-start stamp on seeded anchors,
  one new event and its `remember_event` ledger row.** Cost: a future start-time write
  must be added to the rule, or the gate fails.
- **The listener waits for the node's own count** (`GetStoreStatus`, at least 3 arrays,
  30 s limit) instead of a fixed sleep. Cost: a slow match costs time, up to the limit.
- **Report, run folder and overlay sit beside `--report`**, with a marker file. The gate
  deletes only folders that hold its marker. Cost: the overlay (84 MB) stays until the
  next run or a manual delete.
- **ADR-0024 is Proposed**, like ADR-0021 to ADR-0023, until the team reviews it. Cost:
  none; accepting it later is a status change.
- **The M0 evidence section says the gate passed on 2026-11-05.** It was written into the
  commit before the recipe run on that commit; the run then passed. Cost: a later pin
  move must update that sentence.
- **Agent links name commit `91ffe25`.** Cost: someone must move them when the agent
  publishes replacement pages.
- **The harvest page now tells the agent to never-list `remember_event`, `find_events`
  and the five object writes.** It follows the page's existing rule for people
  services. Cost: the agent owner may decide otherwise; the text is in a Proposed page.
