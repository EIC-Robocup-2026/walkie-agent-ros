### D8 decisions, each with its cost

1. **`thing` matches names, `text` adds caption and printed text.** Names are the label,
   other labels, aliases, official name and category. `ObjectQuery.thing` documents the
   names. Cost: "the box that says fragile" needs the word in `text`, not `thing`.
2. **With a vector, the cosine gate applies only to a nonempty `thing`, and `text` is not
   required of an object that has a vector.** Cost: a vector search with text may return
   objects that lack the words, ranked by cosine.
3. **An object with no vector falls back to the words, every token required.** Cost:
   such an object scores with lexical closeness 1, against a vector object's
   `(cos+1)/2`, so the two kinds mix in one ranking.
4. **Exact cosine over all of the map's vectors, then the filters.** Cost: CPU per
   search, measured above. Reversible behind the same API.
5. **`get_object` returns every surface with an honest `geometry_valid`.** Cost: a client
   must read the flag, not assume a listed surface is usable.
6. **`inside` with a surface key is `INVALID`. `near` with a surface key uses its anchor's
   centre.** Cost: "near shelf 2" measures from the whole anchor.
7. **A `near` reference with no box is `INVALID`. A discarded `near` reference is `OK` with
   nothing.** Cost: a client must tell "no geometry" from "nothing near".
8. **Nearest and farthest use 3D distance from the frame's origin. Left and right use the
   frame's y axis.** Cost: height counts, so an object on a high shelf is farther.
9. **An unknown room is `NOT_FOUND`** in search, contents and events. Cost: a typo is a
   refusal, not an empty result.
10. **Priors skip anchor-layer and relation queries.** Their truncation is ORed into
    `truncated`. Cost: a client cannot tell which list was cut.
11. **An empty model name with `use_embedding` is `INVALID`, an unknown one `UNSUPPORTED`.**
    Cost: none known.
12. **The snapshot holds every non-tombstone state, with `sequence` 0, published once.**
    In wall mode at start, after a fresh seed's anchors are stamped. In a sim on the first
    `/clock` sample. Cost: it shows candidates too, and it never updates until the core
    publishes again.
13. **`map_valid` equals `memory_enabled`.** Memory mode only starts behind the map gate.
    Cost: none while the gate is the only path to memory mode.
14. **Legacy `get_store_status` reads no map and has no `store_id`.** A legacy store has
    no `store_meta` row. Cost: a client must treat an empty `store_id` as "no run
    identity".
15. **Event TF at exactly the node's time, 50 ms wait, no latest fallback.** Cost: a line
    written while TF lags has no pose, and the wait blocks the executor.
16. **A retry of a forgotten line returns id and time, empty text, person and session 0.**
    Cost: the caller learns that the line existed, and nothing else.
